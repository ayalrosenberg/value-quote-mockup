# Value Quoting — mockup

A clickable mockup of a single quoting engine for the Value divisions: quotes list, eight guided steps with a live letter, approvals, quote page and set-up. All seven divisions run end to end.

**This is a design mockup, not a working system.** Every price, customer, person, insurer and policy number in it is invented. Nothing is sent anywhere; what you enter is kept in your own browser only. "Start the demo again", under the avatar at the top right, restores the sample quotes.
